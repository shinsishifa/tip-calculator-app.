# 💸 Tip & Bill Split Calculator App

A dynamic Tip & Bill Split Calculator application built using **Flutter** and **Dart**. Designed to instantly calculate tip amounts, split bills evenly across multiple people, and present per-person costs in real time.

---

## 🌟 Key Features

* **Real-time Per-Person Calculation:** Instantly updates total bill, individual share, and tip amount as inputs change.
* **Interactive Tip Controls:** Choose quick preset percentages (*10%, 15%, 20%, 25%*) or adjust with a smooth `Slider`.
* **Dynamic Split Counter:** Easily add or subtract group members to split the bill evenly.
* **Clean UI Layout:** Minimalist card dashboard for quick reading.

---

## 🛠️ Built With

* **Flutter** - Cross-Platform UI Toolkit
* **Dart** - Programming Language
